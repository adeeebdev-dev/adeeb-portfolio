# Adeeb Portfolio

A modern personal portfolio website built from scratch using Python and Flask.

## 🚀 Features

- Modern dark glassmorphism design
- Responsive portfolio interface
- About, Skills, Projects, Experience and Certificates sections
- Database-driven project management
- Project category filtering
- Individual project detail pages
- Admin authentication
- Admin dashboard
- Add, edit and delete portfolio content
- Contact form with database storage
- Dark and light mode
- CSRF protection and form validation
- Secure password hashing
- SEO basics including sitemap and robots.txt

## 🛠️ Tech Stack

### Backend
- Python
- Flask
- Flask Blueprints
- SQLAlchemy
- SQLite

### Frontend
- HTML5
- CSS3
- JavaScript
- Jinja2

### Authentication & Security
- Flask-Login
- Werkzeug Password Hashing
- Flask-WTF
- CSRF Protection
